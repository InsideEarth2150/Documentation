These are reverse engineered LostSouls scripts from Scripts.wd package They are not the most up to date scripts (there were newer versions that came with later patches).

The scripts are not very same as the original scripts written by Reality Pump, but they are equivalent scripts that produce exactly the same binaries when compiled. There are no function/variable names etc. - the code looks as if it was produced by some decompiler, although it was achieved manually with a huge help of EarthFileReader (https://github.com/GvardianDLVII/EarthFileApi). No refactoring/fixing/cleanup has been applied.

Check other directories in this repository for v2.1 scripts.

AI features

NameValueDescription
0x1IsAlive flag. It is used by IsAlive function. Cannot be modified by EnableAiFeatures.
0x2AI feature responsible for creating new unit templates (Headquarter building feature). Cannot be modified by EnableAiFeatures.
0x4Flag that forces resetting platoon sizes to default. Cannot be modified by EnableAiFeatures.
0x8Unknown. Cannot be modified by EnableAiFeatures.
aiBuildMiningBuildings0x10AI builds mine & refinery if needed
aiBuildMiningUnits0x20AI builds harvesters or container carriers if needed
aiControlMiningUnits0x40AI keeps harvesters or container carriers busy
aiBuildSupplyBuildings0x80AI builds supply centers
aiBuildSupplyUnits0x100AI builds supply units
aiControlSupplyUnits0x200AI assigns supply units to buildings
aiBuildPowerBuildings0x400AI takes care of energy distribution
aiBuildResearchBuildings0x800AI builds research building(s)
aiControlResearches0x1000AI decides which researches it should invent
aiControlDefense0x2000AI checks buildings periodically, and sends defensive platoons if needed
aiControlOffense0x4000AI sends periodically attack to the enemy base
aiBuildBuilders0x8000AI builds Builders if needed
aiBuildRepairers0x10000AI builds repairers and order them tu repair base. No, it doesn't order anything - they just stay idle unless something gets damaged in their range of operation
aiBuildShadows0x20000AI builds and uses shadows. "Uses" is again a bit of an overstatement.
aiBuildScreamers0x40000AI builds and uses screamers
aiBuildSuperAttack0x80000 AI builds and uses mass destruction weapon
aiEnabled0x100000AI enabled/disable
aiBuildTanks0x200000AI takes care of building ground units
aiBuildShips0x400000AI takes care of building ships
aiBuildHelicopters0x800000AI takes care of building helicopters
aiBuildCivilFactory0x1000000AI builds Civil Vehicle Factory if needed
aiBuildMilitaryFactory0x2000000AI builds Military Factory if needed
aiBuildShipyard0x4000000AI builds Shipyard if needed (only if enemy is building it too)
aiBuildBuildings0x7080c90AI builds buildings. Combination of aiBuildShipyard, aiBuildMilitaryFactory, aiBuildCivilFactory, aiBuildSuperAttack, aiBuildResearchBuildings, aiBuildPowerBuildings, aiBuildSupplyBuildings, aiBuildMiningBuildings. It deosn't include aiDefenseTowers, so it is possible that after calling EnableAIFeatures(aiBuildBuildings, false), AI would still build towers - this is just a theoretical possiblity that hasn't been verified.
0x8000000AI scales to its opponent. For example, AI will try to build as many factories as main enemy has. Can be specified only by number.
aiBuildSpecialUnits0xF8000AI builds screamers/schadows etc Combination of aiBuildSuperAttack, aiBuildScreamers, aiBuildShadows, aiBuildRepairers and aiBuildBuilders. Especially aiBuildSuperAttack (MDW) and aiBuildBuilders look a bit out of place here.
aiRush0x10000000AI tries to make first attack as soon as possible
aiUpgradeCannons0x20000000AI upgrades cannon. The feature controls AI ability to mount weapons on buildings.
aiEverything0xFFFFFFF2all flags
aiDefenseTowers0x40000000AI builds defence towers
aiRejectAlliance0x80000000AI allways reject player's offer of alliance

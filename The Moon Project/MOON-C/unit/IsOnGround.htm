object - commandobject - unit 

int IsOnGround()

Scope: private

Parameters
none

Return values
True if unit is on ground (helicopter has landed), false otherwise.

Description
[MP]

IEO Description

It is not clearly stated, but the function will return true not only if it is called on an air unit that has landed, but also if called on any ground unit. It will return false if called on non-unit, for example building.

int GetIFFNumber()

Scope: public

Parameters
none

Return values
IFF-number of player to which this unit belongs.

Description
IFF-number is a player number from range 0-15.
Its number of bit set to 1 in value returned by GetIFF.

IEO Description

The function will work properly if called on objects of non-unit class, like buildings.

object - commandobject - unit 

int IsLandTarget()

Scope: public

Parameters
none

Return values
True if it is land object (unit or building) (can be hit e.g. by cannon or laser), false otherwise.

Description

IEO Description

It returns true if target is not null and is either:
  • an instance of building class
  • an instance of passive class
  • an instance of unit class and IsHelicopter returns false

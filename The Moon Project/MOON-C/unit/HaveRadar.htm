object - commandobject - unit 

int HaveRadar()

Scope: private

Parameters
none

Return values
True if unit have radar attached, false otherwise.

Description

IEO Description

The function iterates over all 4 slots and subslots in search of LookRoundEquipment that is of Radar type (type is validated bitwise against 0x2). Although it can be called on other entities than Unit, it will return false in such case, even if called on an object of Building class (which can have radars). Returns false if called on null object.

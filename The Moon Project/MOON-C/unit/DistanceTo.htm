object - commandobject - unit 

int DistanceTo(int nX, int nY)

Scope: private

Parameters
nX - X-coordinate of point.
nY - Y-coordinate of point.

Return values
Distance to point (nX, nY) from our location.

Description

IEO Description

Calculates approximate distance to target. See object's Distance function for more details about calculation. It returns 0 if called on non-unit, such as Building.

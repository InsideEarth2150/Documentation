object - commandobject - unit 

int GetBuildingType()

Scope: public

Parameters
none

Return values
If unit is a building than returns it's type, if not returns 0.

Description

IEO Description

Returned value is of BuildingType. Since buildingNormal has numeric value of 0, and the function returns 0, then it seems it is not possible to check if unit is a building of "buildingNormal" type, unless combined with IsBuilding function.

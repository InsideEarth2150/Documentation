unit object

object
 +-- commandobject
      +-- unit

Description

Object unit is base object for units of different types (like tanks, builders, harvesters etc.). This object implements functions common for all types of units.
Usually functions which are returning pointer to objects are returning unit type (at least in objects derived from unit).
Unit is not base type for user unit scripts. You should use particular objects like civil, tank, repairer etc.

IEO Description

This class name is misleading as it is not really a "unit" entity - it can be also a building or passive (although according to hierarchy it can accept commands...) Unfortunately the hierarchy in Scripting documentation does not match actual in-game class hierarchy, hence there is a bit of a mess in here. The scripting hierarchy seems to be just an artificial creation that is used just for parsing scripts, while in fact all calls are made on base abstract class virtual functions that can happen to have implementation or will just do nothing or return false if called. Methods that were reviewed are marked with * sign. They will often contain additional comments or other helpful info that was not present in the original documentation.

object - commandobject - unit 

int IsLandUnit()

Scope: public

Parameters
none

Return values
True if it is unit moving by land or water (can be hit e.g. by cannon or laser), false otherwise.

Description

IEO Description

The method validates ObjectType property that is set in parameters. It will return false if target is null, is not an instance of Unit class (0xc00101) or the ObjectType is one of the following (naming convention from parameters file):
  • helicopter - 0x0018
  • harrier - 0x0020
  • plane - 0x0028
Technically, after validating that enity is not null and is of unit class, it uses and negates IsHelicopter function logic.

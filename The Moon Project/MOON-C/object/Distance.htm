object 

int Distance(int nX1, int nY1, int nX2, int nY2)

Scope: public

Parameters
nX1 - x-coordinate of the first point.
nY1 - y-coordinate of the first point.
nX2 - x-coordinate of the second point.
nY2 - y-coordinate of the second point.

Return values
Distance between (nX1, nY1) and (nX2, nY2) points.

Description

IEO Description

The returned value is just an approximation of the distance, not the exact value. The formula is the second circle approximation (thx to Noctis for naming it) and is as follows: max(abs(nX1-nX2),abs(nY1-nY2)) + 0.5*min(abs(nX1-nX2),abs(nY1-nY2)).

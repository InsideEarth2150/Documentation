object - commandobject - platoon 

int GetCannonShootRange(int nUnit, int nCannonNum)

Scope: private

Parameters
nUnit - unit number
nCannonNum - cannon number.

Return values
Range of fire of cannon number nCannonNum.

Description

IEO Description

Returns cannon shoot range (see tank's GetCannonShootRange) of unit at index given in parameter. Return 0 if platoon is null or if unit or weapon index is out of range

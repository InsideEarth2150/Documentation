object - player 

void SetScriptUnit(int nUnitIndex, unitex uUnit)

Scope: public

Parameters
uUnitIndex - index - from 0 to 19
uUnit - unit

Return values
none

Description
Sets pointer unit in common area at the specified index. it is useful to establish comunication comunication between missions or for example tracing unit (see LC campaign and fang)

IEO Description

Data in the "common area" is shared by given player's instances on all levels. If you set data using mission's player instance, it will be available in other levels (main base, otehr bases and next missions). Data is stored in a 20-element array, what limits range of nUnitIndex parameter. Calling this function with index <0 or >= 20 will cause no effect.

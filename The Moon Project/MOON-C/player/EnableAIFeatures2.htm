void EnableAIFeatures2(int nFlags, int nEnable)

Scope: public

Parameters
nFlags:
ai2BuildingTowers = 0x2 - AI defences heavilly attacked buildings by building defence towers
ai2BuildFromStartingPoint = 0x4 - AI tries to build everything as close to starting point as possible
ai2BuildSappers = 0x8 - AI builds sappers and order them to mine area around
ai2ChooseEnemy = 0x10 - allows AI to choose enemy (otherwise you have to use choose enemy function)
ai2NeutralAI = 0x20 - AI thread others AI as neutral
ai2BNSendResult = 0x80000000- player's result may be sent to EarthNet server (you can only disable this flag)

Return values
none

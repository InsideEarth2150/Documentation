object - player 

int GetNumberOfUnits(int nUnitFlags)

Scope: public

Parameters
nUnitFlags - one of:

chassisTank - 0x1
chassisAmphibianTank - 0x2
chassisShip - 0x4
chassisHelicopter - 0x8
chassisMask chassisAny - 0xFF
chassisMiner unitMiner - 0x100
chassisBuilder unitBuilder - 0x200
chassisHarvester unitHarvester - 0x400
chassisSupplier unitSupplier - 0x800
chassisFake unitFake - 0x1000
unitArmed - 0x2000
unitShadow - 0x4000
unitScreamer - 0x8000
unitObserver - 0x10000
unitCarrier - 0x20000
unitRepairer - 0x40000
unitTransporter - 0x40000
unitAny - 0xFFF00

Return values
number of units

Description
Returns number of units of certain kind

IEO Description

Most likely unintended, masks unitRepairer and unitTransporter have the same code. The method can be used to get number of units matching multiple flags, such us: GetNumberOfUnits(chassisShip | unitArmed). The first 4 masks (chassis masks) seem to be taken into account only if other masks match and are treated a bit separately. For example: GetNumberOfUnits(chassisTank | unitArmed) will return only units that are both armed and with tank chassis. However, GetNumberOfUnits(chassisTank | chassisShip | unitArmed) will return number of units that are armed AND of type tank OR ship. The exact behaviour of this function may require further tests.

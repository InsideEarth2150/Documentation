object - player 

int GetNumberOfUnits(int nUnitFlags)

Scope: public

Parameters
nUnitFlags - Original parameter description was incorrect. It is a combination of Chassis flags and Unit flags. The values of chassis flags and unit flags are treated independently. See description for more information.

Return values
number of units

Description
Returns number of units of certain kind

IEO Description

Most likely unintended, masks unitRepairer and unitTransporter have the same code. The method can be used to get number of units matching multiple chassis and unit flags, such as: GetNumberOfUnits(chassisShip | unitArmed). Chassis and Unit flags are taken into account separately, which means that if flags from both groups are specified, unit needs to meet criteria for both unit and chassis flags. For example: GetNumberOfUnits(chassisTank | unitArmed) will return only units that are both armed and with tank chassis. However, GetNumberOfUnits(chassisTank | chassisShip | unitArmed | unitShadow) will return number of units that are armed OR with shadow AND of type tank OR ship. The exact behaviour of this function may require further tests.

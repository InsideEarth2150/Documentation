object - player 

void CreateDefaultUnit(int nX, int nY, int nZ)

Scope: public

Parameters
nX - X-coordinate
nY - X-coordinate
nZ - 1-tunnel 0-ground

Return values
none

Description
Creates default units for player race (probe in case of LC, builder in case of UCS and ED

IEO Description

It literally calls CreateUnitEx. The parameters are:
  • CreateUnitEx(nX, nY, nZ, null, "UCSUBU1", null, null, null, null, -1) for UCS
  • CreateUnitEx(nX, nY, nZ, null, "EDUBU1", null, null, null, null, -1) for ED
  • CreateUnitEx(nX, nY, nZ, null, "LCUOB1", "LCSOB1", null, null, null, -1) for UCS
The parameters are hardcoded, so you cannot provide a different "default unit", give it shield etc.

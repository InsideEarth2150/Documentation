object - player 

int GetScriptData(int nDataIndex)

Scope: public

Parameters
nDataIndex - index - from 0 to 19

Return values
data

Description
Gets integer from common area (shared between missions, campaigns and bases)

IEO Description

Data in the "common area" is shared by given player's instances on all levels. If you set data using mission's player instance, it will be available in other levels (main base, otehr bases and next missions). Data is stored in a 20-element array, what limits range of nDataIndex parameter. Calling this function with index <0 or >= 20 will always return 0.

int IsInWorld(int nWorldNum)

Scope: public

Parameters
none

Return values
true/false

Description
Returns if object is in world specified by number (mission is 0 bases has numbers 1,2,3)

IEO Description

Nothing to add. Will return false if the invocation target is null or the world number is out of 0-3 range (it won't crash).

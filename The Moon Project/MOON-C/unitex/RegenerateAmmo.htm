object - commandobject - unit - unitex

void RegenerateAmmo()

Scope: public

Parameters
none

Return values
none

Description
Reloads ammo

IEO Description

Refills ammo for all weapons and subweapons. In case of the target being a minelayer, it restores its mines as well. The function can also refill ammo for buildings of type buildingSilos (0x14) - note that this is the MDW type that needs to be resupplied, not the one that gets recharged over time.

object - commandobject - unit - tank

int CannonRequiresSupply(int nCannonNum)

Scope: public

Parameters
nCannonNum - cannon number.

Return values
True if cannon number nCannonNum requires external ammo supply, false otherwise.

Description
Result of this function doesn't depend on current ammo count.
If nCannonNum == -1 then function returns true if at least one of cannons requires external ammo supply.

IEO Description

Nothing to add, although it is worth emphasizing that the function just checks if the cannon is resupplyable, not if it is out of ammo. For instance, heavy electro cannon will always return false, while heavy rockets will always return true.

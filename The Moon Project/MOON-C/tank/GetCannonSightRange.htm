int GetCannonSightRange(int nCannonNum)

Scope: private

Parameters
nCannonNum - cannon number.

Return values
Range of view (enemies) of cannon number nCannonNum.

Description

IEO Description

Returns cannon sight range of a cannon at given index. See tank's GetCannonType for indexation rules. The value includes bonsuses from exp level and banner.

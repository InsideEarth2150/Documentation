object - commandobject - unit - tank

int GetCannonType(int nCannonNum)

Scope: private

Parameters
nCannonNum - cannon number.

Return values
Type of cannon number nCannonNum attached on tank:
cannonTypeLaser - laser,
cannonTypeLaserSDI - SDI (on buildings only),
cannonTypeElectric - electric cannon,
cannonTypeMachine - machine gun,
cannonTypeCannon - cannon,
cannonTypeRocket - rocket launcheer,
cannonTypeAutoRocket - rocket launcher with self-guided missiles,
cannonTypeBallisticRocket - ballistic rocket,
cannonTypeSonic - sonic cannon,
cannonTypeAntiRocket - anti-rocket,
cannonTypeDropBomb - Grenade launcher,
cannonTypeBomb - air-bombs,
cannonTypeIon - ion cannon,
cannonTypePlasma - plasma cannon,
cannonTypeSuperPlasma - plasma cannon building.

Description

IEO Description

Returns the cannon type at given index as described, however the way the index is calculated may not be that obvious. The indexation starts with 0. The game iterates through all slots and subslots, counts weapons and stops at target index. It returns the cannon type of weapon at that slot. For example, HT Ural with HeavyRockets and HeavyCannon + SmallRockets on top, would have weapon indices as follows: hR - 0,hC - 1, sR - 2. Ural with hC and hC, would be: frist hC - 0, second hC - 1. Ural with hC+MG and hL+sL would be: hC - 0, MG - 1, hL - 2, sL - 3. If we replaced MG in the last example with banner (which is not of weapon class), it would be: hC - 0, hL - 1, sL - 2. Returns 0 (which is ambiguous with cannonTypeLaser btw...) if target is null or index is out of range. The function can also return value 0xf which is Earthquake cannon type.

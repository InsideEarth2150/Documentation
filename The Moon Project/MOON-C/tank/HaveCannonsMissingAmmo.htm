object - commandobject - unit - tank

int HaveCannonsMissingAmmo()

Scope: private

Parameters
none

Return values
True if tank have cannon which requires external ammo supply and this cannon have missing ammo, false otherwise.

Description

IEO Description

Returns true if cannon ammo count is not equal to max ammo count. This means, that it checks if cannon can be resupplied at the moment - it doesn't determine if cannon is out of ammo, or below some resupply threshold etc. The function should work on buildings as well.

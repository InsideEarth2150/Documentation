object - commandobject - unit - tank

int GetCannonShootRange(int nCannonNum)

Scope: private

Parameters
nCannonNum - cannon number.

Return values
Range of fire of cannon number nCannonNum.

Description

IEO Description

Returns the shoot range of a cannon at given index. See tank's GetCannonType for indexation rules. Returns 0 if target is null or index is out of range. The value includes bonuses from ammo, exp level and banner. The final value (including modifiers) is reduced by 25% for sonic and earthquake weapons, that's why it will return 3 for sonic with range 5 (5*0.75=3.75) and 4 for sonic in banner range with range 5+1 (6*0.75=4.5).
